# add-subtract-ex.nvim features
- [x] Toggle word pairs (true/false, yes/no, on/off), casing kept
- [x] Invert symbol pairs (&&/||, ==/!=, <=/>=, ++/--, +/-)
- [x] Defer to native numbers (decimal, hex 0xFF, binary 0b1010)
- [x] Shift letters (a -> b), with a count
- [x] Step dates (yyyy-MM-dd, dd/MM/yyyy, MM/dd/yyyy)
- [x] Step times (HH:mm, HH:mm:ss, 9:30 PM)
- [x] Repeat any step with .
- [x] Change visual selections, step progressively, and fill blank sequences
- [ ] Toggle Markdown checkboxes
